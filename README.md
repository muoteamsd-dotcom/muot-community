# MUO Community — النسخة التجريبية الأولى

تطبيق ويب تقدمي (PWA) ثابت بلا خطوة بناء، جاهز للرفع على GitHub Pages. يقرأ المحتوى ويكتبه عبر Supabase مباشرة من المتصفح.

## التشغيل
1. أنشئ مشروعاً في Supabase، وشغّل `sql/schema.sql` في SQL Editor (بعد استبدال `PUT-ADMIN-EMAIL-HERE` ببريدك).
2. من Authentication: أنشئ مستخدماً (بريدك) وعطّل التسجيل العام (Allow new users to sign up).
3. ضع `SUPABASE_URL` و`SUPABASE_ANON_KEY` في `config.js`. مفتاح anon آمن للظهور في الواجهة، ولا تضع service_role أبداً.
4. ارفع المجلد إلى مستودع GitHub، ثم Settings > Pages > Source: GitHub Actions. الـ workflow جاهز.
5. افتح `#/admin` وسجّل الدخول لإضافة المحتوى.

بدون `config.js` معبأ يعمل التطبيق بمحتوى تجريبي معلَّم بوضوح، دون لوحة إدارة.

## الأمان
الحماية بالكامل في قاعدة البيانات: Row Level Security تسمح للزوار بقراءة المنشور فقط، وتحصر الكتابة ورفع الملفات بالبريد المسجل في `admin_emails`.

## القرارات التقنية
- HTML/CSS/JS بدون إطار عمل، لأن GitHub Pages لا يشغّل خادم Next.js، وتجنباً لتعقيد غير لازم في النسخة الأولى.
- التوجيه بـ hash (`#/news/ID`) لأن الصفحات الديناميكية لا تُولَّد مسبقاً على الاستضافة الثابتة.
- الـ Service Worker لا يخزّن طلبات Supabase ولا الصوت.

## غير منفّذ بعد
- صفحة مستقلة لكل حلقة (التشغيل من قائمة البرنامج حالياً).
- المواسم في الواجهة (الجدول جاهز في قاعدة البيانات).
- محرر نصوص مرئي (المحتوى نص بسيط: فقرات، `##` للعناوين، رابط صورة في سطر مستقل).
- إدارة الإعدادات والوسائط من اللوحة (جدولا `platform_settings` و`media_assets` جاهزان؛ كل رفع يُسجَّل تلقائياً).
- الاختبار على أجهزة فعلية.
